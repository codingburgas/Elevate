## 🎯 What Does It Do?

**MovieManager** lets you manage a personal list of movies from your computer. Here's what you can do with it:

- ➕ **Add movies** to your collection
- ❌ **Remove movies** you no longer want
- 🔍 **Search & filter** to find a specific movie
- ⭐ **Rate & review** movies you've watched

---

## 💻 How to Download & Run It

Don't worry if you've never done this before — just follow the steps one by one.

### Step 1 — Make sure you have Git installed

Open **CMD** (press `Windows key + R`, type `cmd`, press Enter) and type:

```
git --version
```

If you see a version number, you're good. If not, download Git from [git-scm.com](https://git-scm.com) and install it.

### Step 2 — Download the project

In CMD, type:

```
cd C:\Users\YourName\Desktop
```

(replace `YourName` with your actual Windows username)

Then:

```
git clone https://github.com/codingburgas/Elevate.git
```

This will create an `Elevate` folder on your Desktop.

### Step 3 — Open the project

Open the `Elevate` folder and double-click `MovieManager.sln` — this will open it in **Visual Studio**.

### Step 4 — Run it

In Visual Studio, just press **F5** (or the green ▶ Play button) and the program will start.

---

## 🎮 How to Use It

When the program starts, it will show you a menu in the console window. Use the number keys to pick an option:

1. **Add a movie** — type in the title, genre, year, etc.
2. **Remove a movie** — pick a movie from your list to delete it
3. **Search / Filter** — look up a movie by name or genre
4. **Rate & Review** — give a movie a score and write your thoughts

Just follow what it says on screen — it'll guide you through everything.
